# ProSprite
Editor sprite landscape + mode Coba platformer (Idle / Walk / Jump). UI = WebView, kode di app/src/main/assets/www.

## Dari Termux
    pkg install unzip git
    unzip ProSprite.zip -d ProSprite && cd ProSprite
    git init && git add . && git commit -m "ProSprite"
    git branch -M main
    git remote add origin https://github.com/USERNAME/prosprite.git
    git push -u origin main

Build otomatis jalan di tab Actions. APK ada di Artifacts (ProSprite-APK) dan di Releases (ProSprite.apk).
